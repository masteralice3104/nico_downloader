# nico downloader

ニコニコ動画の保存を支援する、非公式のChrome拡張機能です。通常動画・ショートをMP4（動画）またはAAC（音声のみ）で保存できます。

**[Chrome Webストアから導入](https://chromewebstore.google.com/detail/nico-downloader/dncjcadpoakefjpnabimpalenliehbig) · [詳しい使い方はWikiへ](https://github.com/masteralice3104/nico_downloader/wiki)**

このREADMEとWikiは `v4` ブランチの実装を基準にしています。ストア配布版とは、画面や機能の反映時期が異なる場合があります。

## はじめに

1. 拡張機能のオプションを開き、最上部の使い方を確認してチェックを入れます。
2. **「初期設定モード」をオフにし、「設定を保存」を押します。**
3. 動画ページの保存ボタン、またはショートのダウンロードアイコンを押します。
4. ダウンロード・変換が終わるまで待ち、Chromeのダウンロード一覧や保存先を確認します。

保存先と保存ダイアログの有無はChromeの設定に従います。処理中はアイコンが回転し、保存要求後はチェックアイコンに変わってグレーアウトします。

## 主な機能

- 通常動画（既定で `/watch/sm数字`）とショート（`/shorts/ss数字`）に保存ボタンを表示。
- MP4・AACでの保存と、基本のファイル名設定。
- **通常動画専用**のカスタム保存名。投稿者名・タイトル・動画番号を選んだ順に組み合わせ。
- 読み込み記録から親m3u8を取得。確認できない場合はシステムメッセージから取得。
- 動画データ取得時の通信再試行、進捗表示、保存終了表示。

ショートには通常動画用のカスタム保存名は反映されず、「基本のファイル名」が適用されます。ニコニコ大百科の掲示板向け補助機能も含まれます。

## 動作環境・注意事項

従来から案内しているサポート環境は以下のとおりです。

| 項目 | 環境 |
| --- | --- |
| ブラウザー | Chrome最新版。Chrome以外（Edgeなど）はサポート対象外 |
| OS | Windows 11 23H2以降。macOSは動作保証対象外 |
| CPU | AMD Ryzen Zenプロセッサより新しいプロセッサ |
| メモリ | 8GB以上、推奨16GB以上。8GB未満はサポート対象外 |
| 回線 | 100Mbps以上が目安。ニコニコへの通信が安定していること |

- 動画データの処理に多くのメモリを使用します。長時間の動画では特にご注意ください。
- 暗号化された動画には対応しません。不正な目的で使用しないでください。
- **プロフェッショナル設定（ここの設定についてはサポートしません）。** 通常は変更不要です。
- 画質選択・コメントのダウンロードは、現在の設定画面にはありません。

## 不具合・要望・変更の提案

うまく動かないときは、[Wikiの対処方法](https://github.com/masteralice3104/nico_downloader/wiki/困ったときは)を確認し、[Issueを作成してください](https://github.com/masteralice3104/nico_downloader/issues/new)。バージョン、通常動画／ショートの区別、再現手順、最後のエラーを日本語で記載してください。

改修の提案はプルリクエストで受け付けています。内容を確認したうえで、採用する場合があります。
