# nico downloader

ニコニコ動画の保存を支援する、非公式のChrome拡張機能です。通常動画・ショートをMP4（動画）またはAAC（音声のみ）で保存できます。

**[Chrome Webストアから導入](https://chromewebstore.google.com/detail/nico-downloader/dncjcadpoakefjpnabimpalenliehbig) · [詳しい使い方はWikiへ](https://github.com/masteralice3104/nico_downloader/wiki)**

このREADMEとWikiは `v4` ブランチの実装を基準にしています。ストア配布版とは、画面や機能の反映時期が異なる場合があります。

## おことわりと怒りの表明
1. 基本的にsm～以外の動画では動作しないようにしてあります
1. 一部の動画に暗号化されている動画がありますが、いろいろなところに抵触する為対応しません
1. 絶対に邪な使い方はしないで下さい
2. しょぼいスペックのPCではまず動きません

※現在の実装では、通常動画に加えてニコニコショート（`/shorts/ss数字`）にも対応しています。

## はじめに

1. 拡張機能のオプションを開き、最上部の使い方を確認してチェックを入れます。
2. **「初期設定モード」をオフにし、「設定を保存」を押します。**
3. 動画ページの保存ボタン、またはショートのダウンロードアイコンを押します。
4. ダウンロード・変換が終わるまで待ち、Chromeのダウンロード一覧や保存先を確認します。

保存先と保存ダイアログの有無はChromeの設定に従います。処理中はアイコンが回転し、保存要求後はチェックアイコンに変わってグレーアウトします。

## 主な機能

- 通常動画（既定で `/watch/sm数字`）とショート（`/shorts/ss数字`）に保存ボタンを表示。
- MP4・AACでの保存と、基本のファイル名設定。
- **通常動画専用**のカスタム保存名。投稿者名・タイトル・動画番号を選んだ順に組み合わせ。
- 読み込み記録から親m3u8を取得。確認できない場合はシステムメッセージから取得。
- 動画データ取得時の通信再試行、進捗表示、保存終了表示。

ショートには通常動画用のカスタム保存名は反映されず、「基本のファイル名」が適用されます。ニコニコ大百科の掲示板向け補助機能も含まれます。

## 動作環境・注意事項

従来から案内しているサポート環境は以下のとおりです。

| 項目 | 環境 |
| --- | --- |
| ブラウザー | Chrome最新版。Chrome以外（Edgeなど）はサポート対象外 |
| OS | Windows 11 23H2以降。macOSは動作保証対象外 |
| CPU | AMD Ryzen Zenプロセッサより新しいプロセッサ |
| メモリ | 8GB以上、推奨16GB以上。8GB未満はサポート対象外 |
| 回線 | 100Mbps以上が目安。ニコニコへの通信が安定していること |

- 動画データの処理に多くのメモリを使用します。長時間の動画では特にご注意ください。
- 暗号化された動画には対応しません。不正な目的で使用しないでください。
- **プロフェッショナル設定（ここの設定についてはサポートしません）。** 通常は変更不要です。
- 画質選択は、現在の設定画面にはありません。コメントJSONの保存は通常動画のみ、設定で有効にした場合に利用できます。

### 開発中（次回バージョン向け）

以下は `5.0.0.22` のバージョン番号設定後、`v4` ブランチで追加・修正した内容です。バージョン番号はまだ更新していません。

#### 追加

- 通常動画のコメントJSONを一緒に保存する設定を追加（初期状態はオフ）。有効化・設定保存後に動画ページを再読み込みすると、動画の保存ボタンで同じ名前の `.json` も保存します。ページが `https://public.nvcomment.nicovideo.jp/v1/threads?pc=1` へのPOSTで受信したJSONのうち、取得時と保存対象の動画番号が一致する最新の1レスポンスをそのまま保存します。全期間のコメントの追加取得・結合やショートには対応しません。未受信・取得失敗の場合は理由をコンソールに表示し、動画の保存は継続します。Chromeの複数ファイルのダウンロード許可が必要になる場合があります。
- ニコニコショート（`/shorts/ss数字`）のダウンロードボタンと、表示中のタイトル取得に対応。
- 通常動画専用のカスタム保存名を追加。投稿者名・動画タイトル・動画番号を選んだ順に組み合わせられます。ショートは基本のファイル名を使用します。
- 通常動画・ショートそれぞれの保存名プレビューを追加。
- 読み込み記録を監視して親m3u8を取得し、取得できない場合は従来のシステムメッセージ経路へ切り替える処理を追加。
- ショート用のURL判別パターンを通常動画用とは別に設定できるように変更。
- m3u8取得成功時のURLと、失敗した段階・理由をコンソールに表示。
- 日本語Wikiを整備し、設定画面にWikiへのリンクとIssue作成用の案内を追加。

#### 変更

- FFmpeg 4.3.1ベースの旧Coreから、公式の単一スレッド版 `@ffmpeg/core 0.12.10`（FFmpeg 5.1.4）へ更新。旧Coreの `ccall` 呼び出しと終了通知への依存を廃し、現行の `exec`・終了コード・ログAPIへ移行。
- WASM内部の最大メモリを旧Coreの1GiBから新Coreの2GiBへ拡張。初期メモリ32MiBは維持。保存方式・権限・既存のファイル構成は維持。
- 同梱Coreの第三者ライセンスとソース・配布元への案内を更新。

- 設定画面を刷新。ライト／ダーク表示、狭い画面、常時表示の保存ボタンに対応。
- 使い方を設定画面の最上部で強調し、確認チェックを入れるまで設定変更・保存を無効化。チェック状態も保存・復元します。
- 詳細設定を小さな折りたたみ表示に変更し、従来のサポート対象外の注意書きを維持。
- 保存ボタンにダウンロードアイコンを追加。処理中はアイコンが回転し、保存要求後はチェックアイコンでグレーアウトします。
- READMEを要約し、詳しい使い方・設定・トラブル対処はWikiへ案内する構成に変更。

#### 修正

- ページの段階的な読み込みに追従して初期保存ボタンを表示し、設定の取得前は「読込中…」を表示。
- システムメッセージを開く操作で、設定メニューと対象ボタンの表示完了を待つように修正。
- ショートの親m3u8候補を要求時刻で選び、後続の先読みURLによる上書きを抑制。検証途中のクリックでは確認完了を待機します。
- 設定の保存後に値を読み戻し、一致を確認してから保存成功を表示。
- 通信失敗時のエラー加算メソッド名、最大試行回数、待機処理を修正。待機中に画面を止めず、明示的な中断は再試行しません。
- FFmpegの終了通知ではなく終了コード0で成功を判定し、その後に出力読み出しと既存方式の保存要求を実行。
- プレイリスト取得から変換・保存準備まで完了を待機し、成功・失敗にかかわらず処理中状態を解除。失敗後は保存ボタンの押し直しで再試行できるように修正。
- 変換出力の読み出し・保存準備に失敗した場合は保存済みと記録せず、エラーを呼び出し元へ通知。
- FFmpeg変換処理とUTF-8文字列の受け渡しを整理し、日本語タイトルの文字化けと正常終了の扱いを修正。既存の保存方式は維持。
