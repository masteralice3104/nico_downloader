# nico downloader

ニコニコ動画の通常動画・ショートを、MP4（映像と音声）またはAAC（音声のみ）で保存する非公式Chrome拡張機能です。

**現行リリース：5.1.0.0（2026-10-25）**

[Chrome Webストア](https://chromewebstore.google.com/detail/nico-downloader/dncjcadpoakefjpnabimpalenliehbig) · [GitHub Release・配布ZIP](https://github.com/masteralice3104/nico_downloader/releases/tag/5.1.0.0) · [詳しい使い方・Wiki](https://github.com/masteralice3104/nico_downloader/wiki) · [掲示板・質問と相談](https://github.com/masteralice3104/nico_downloader/discussions) · [Issueを作る！](https://github.com/masteralice3104/nico_downloader/issues/new)

このREADMEとWikiは5.1.0.0の実装を説明しています。Chrome Webストアへの公開時期はGitHub Releaseと異なる場合があります。

## おことわりと怒りの表明

1. 基本的にsm～とss～以外の動画では動作しないようにしてあります
2. 一部の動画に暗号化されている動画がありますが、いろいろなところに抵触する為対応しません
3. 絶対に邪な使い方はしないで下さい
4. しょぼいスペックのPCではまず動きません

## 導入する

通常は[Chrome Webストア](https://chromewebstore.google.com/detail/nico-downloader/dncjcadpoakefjpnabimpalenliehbig)から導入してください。

GitHub配布版を使う場合は、ReleaseのAssetsにある **`nico_downloader_5.1.0.0.zip`** をダウンロードして展開します。Chromeの拡張機能管理画面でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」から、展開した`manifest.json`のあるフォルダーを指定してください。更新時は既存の配置先へ展開して拡張機能を再読み込みし、動画ページも再読み込みします。

配布ZIPは無圧縮（ZIP_STORED）で、`manifest.json`がZIPの直下に入っています。GitHubが自動生成する「Source code (zip)」はリポジトリ全体のソースで、拡張機能用の配布ZIPとは別です。

## 保存する

1. オプション最上部の使い方を読み、「使い方を確認しました。設定に進みます。」へチェックを入れます。
2. **「初期設定モード」をオフにして「設定を保存」を押します。**
3. 通常動画の保存ボタン、またはショートのダウンロードアイコンを押します。
4. 取得・変換が終わるまで待ち、Chromeのダウンロード一覧や保存先を確認します。

保存ボタンを右クリックすると、MP4／AACとコメントJSON保存を切り替えられます。変更は即時保存されます。取得・変換中は回転アイコン、保存要求後はチェックアイコンとグレー表示になります。「保存終了」はChromeへ保存を要求した段階であり、ディスクへの書き込み完了を検知する表示ではありません。

ショートで親m3u8を取得できない場合は、ボタンが **「Reloadする」** に変わります。押すと現在のページを再読み込みします。通常動画ではプレイヤーの「設定」→「システムメッセージを表示」で取得できる場合もあります。

## 保存内容と設定

| 項目 | 動作 |
| --- | --- |
| 対象 | 通常動画 `/watch/sm数字`、ショート `/shorts/ss数字` |
| MP4 | 映像と音声を保存 |
| AAC | 音声のみを保存。映像プレイリスト・映像断片の取得を省略 |
| 基本のファイル名 | 動画番号、タイトル、または両方を選択。通常動画・ショート共通 |
| カスタム名 | 通常動画専用。投稿者名・タイトル・動画番号・なしを3枠で選択 |
| コメントJSON | 初期状態はオフ。ページが受信したJSONを動画と同じ確定名の`.json`として保存 |
| メタタグ | 取得できたタイトル・投稿者・タグ・説明・日時・シリーズ・動画番号・4種類の件数などを保存 |

コメントを保存する場合は、設定を有効にして動画ページを再読み込みしてください。通常動画では最後に要求した応答、ショートでは先読みを避けるため最初に要求した応答を使用します。全期間のコメントの追加取得・結合は行いません。未受信・取得失敗の場合も動画の保存は続行します。Chromeから複数ファイルのダウンロード許可を求められる場合があります。

保存先と保存ダイアログの有無はChromeの設定に従います。実行中の保存形式と名前構成は開始時の設定を使います。タイトルや投稿者名は変換直前にも補完するため、最初の表示名から変わる場合があります。禁止文字・予約名・末尾の空白などを調整し、拡張子込みで原則180文字（UTF-16単位）までに収めます。

メタタグの表示は再生ソフトやファイル形式で異なります。MP4ではWindowsの詳細プロパティ向け互換タグ、AACではID3v2を使用します。再生数・コメント数・マイリスト数・いいね数は取得時点の独自タグであり、Windowsに専用の欄が追加されるわけではありません。

ニコニコ大百科の掲示板向け補助機能も含まれます。

## 動作環境と制限

| 項目 | サポート環境 |
| --- | --- |
| ブラウザー | Chrome最新版。Chrome以外（Edgeなど）はサポート対象外 |
| OS | Windows 11 23H2以降。macOSは動作保証対象外 |
| CPU | AMD Ryzen Zenプロセッサより新しいプロセッサ |
| メモリ | 8GB以上、推奨16GB以上。8GB未満はサポート対象外 |
| 回線 | 100Mbps以上が目安。ニコニコへの通信が安定していること |

- 長時間・大容量の動画は、メモリ不足で保存できない場合があります。軽量化は容量無制限を保証するものではありません。
- 同梱する単一スレッド版`@ffmpeg/core 0.12.10`はFFmpeg 5.1.4ベースです。WASMの初期メモリは32MiB、最大は2GiBで、ブラウザー全体の使用量はこれを超える場合があります。
- 画質選択の設定はありません。ページで取得したプレイリストに従います。
- **プロフェッショナル設定（ここの設定についてはサポートしません）。**
- 同梱Coreのライセンス・配布元・ソース案内は[LICENSE](nico_downloader/LICENSE)に記載しています。
